## 📂 Projects Overview

### Task 2: Real Estate Housing Price Prediction

**Objective:** To develop and evaluate machine learning regression models for predicting housing prices.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

**Models Implemented:**
- Ordinary Least Squares (OLS) / Linear Regression
- Ridge Regression
- Lasso Regression
- GridSearchCV for hyperparameter tuning

**Project Workflow:**
1. Load and explore the housing dataset.
2. Perform exploratory data analysis and study feature correlations.
3. Prepare the data for model training.
4. Train and compare regression models.
5. Apply GridSearchCV for hyperparameter tuning.
6. Evaluate model predictions using visualizations and residual analysis.

**Key Outputs:**
- Actual vs. Predicted Values
- Correlation Heatmap
- Model Comparison
- Residual Plot

**Conclusion:** This project demonstrates how regression techniques can be used for housing price prediction. Comparing OLS, Ridge, and Lasso helps assess model performance, while regularization and hyperparameter tuning provide a structured approach to improving model generalization. The final model should be selected based on its evaluation results.

### Task 4: NLP Sentiment Classification on Customer Reviews

**Objective:** To classify customer reviews into positive, negative, and neutral sentiment categories using Natural Language Processing (NLP) and machine learning.

**Technologies Used:** Python, Pandas, Scikit-learn, TF-IDF, Matplotlib.

**Models Implemented:**
- Multinomial Naive Bayes
- Logistic Regression

**Project Workflow:**
1. Load and explore customer review data.
2. Clean and preprocess the review text.
3. Convert text into numerical features using TF-IDF vectorization.
4. Train sentiment classification models.
5. Evaluate model performance using classification metrics and a confusion matrix.
6. Compare the models and test predictions on custom reviews.

**Key Outputs:**
- Customer Sentiment Distribution
- Naive Bayes Evaluation
- Model Comparison
- Custom Review Predictions

**Conclusion:** This project demonstrates a basic NLP pipeline for classifying customer reviews. Text preprocessing and TF-IDF feature extraction enable machine learning models to process textual data. However, the dataset contains only 10 reviews, so the evaluation results are preliminary and cannot establish reliable real-world performance. A larger, balanced, and representative dataset is needed for meaningful evaluation.
